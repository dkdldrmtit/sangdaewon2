### 배포가 실패할 때

- **"Multiple artifacts named \"github-pages\"" 오류**: GitHub 쪽 일시 장애입니다.
  실패한 실행을 Re-run 하지 말고, 새 커밋을 푸시해 새 실행을 만들면 해결됩니다.
  (같은 실행을 재시도하면 이전 시도의 산출물이 남아 동일 오류가 반복될 수 있습니다.)
- 반영이 안 보일 때: 브라우저 캐시일 수 있으니 주소 뒤에 `?v=숫자`를 붙여 열어 확인하세요.

## 내용 업데이트 방법

- **공지 추가**: `index.html`에서 `notice-list`를 찾아 `<li>` 한 줄을 추가합니다.
- **자료 추가** (예: 성남시 공문 스캔):
  1. 파일을 `docs/` 폴더에 넣습니다.
  2. `자료실` 섹션의 해당 카드(`doc pending`)에서 `pending` 클래스를 제거하고,
     `<span class="soon">…</span>`을 `<a class="dl-btn" href="docs/파일명" download>내려받기 ↓</a>`로 바꿉니다.
- **법무법인 지평 종합 검토안 전문 게시 절차** (지평·조합의 공개 확인 후에만 진행):
  1. 확인 전에는 파일을 저장소에 넣지 마십시오. 이 저장소는 Public이므로 `docs/`에 넣는 순간
     링크 여부와 무관하게 누구나 접근할 수 있습니다.
  2. 확인이 끝나면 파일을 `docs/법무법인지평_종합검토안_4안대조와협상경과_2026-09-04.pdf`로 넣고,
     자료실의 지평 카드에서 `pending` 클래스와 `<span class="soon">…</span>`을 제거한 뒤
     내려받기 버튼으로 교체합니다. 공지사항 목록에도 게시 항목을 추가합니다.
- 모든 사실 주장·조문 인용은 조합 안내자료를 근거로 하며, 새 주장을 추가할 때는
  근거 문서를 자료실에 함께 게시하는 것을 권장합니다.

## 원문 대비 표기 정정 사항

사이트 제작 시 안내문 PDF의 다음 표기를 교차 확인 후 바로잡아 반영했습니다.

1. PDF 6쪽 표 머리글 "DL이앤씨 제시안 제32조(공사기간 연장)" → **제29조** 로 표기
   (PDF 7쪽 해설 "DL안 제29조 제3항" 및 DL 계약서 전문 목차와 교차 확인, 제32조는 '공사의 시정명령').
2. PDF 24~25쪽 조합 검토안 제11조 ④·⑤항이 인용하는 "제35조" → **제36조** 로 표기
   (제36조가 '계약의 해제 및 해지', 날인 제출본 전문과 교차 확인).
3. "2026월 6월" → "2026년 6월", "재2조제1항" → "제2조 제1항" 등 명백한 오탈자 정규화.
4. DL 제시안 제9조에서 '②' 항이 두 번 표기된 것은 **DL 원문 표기 그대로**이며, 사이트에 각주로 명시했습니다.
5. 쟁점 07 조합 검토안 제6조 제3항의 제6호·제8호에 유사한 인입공사 항목이 거듭 표기된 것은
   **조합 검토안 원문 표기 그대로**이며, 사이트에 각주로 명시했습니다.
