# 상대원2구역 주택재개발정비사업조합 공사도급계약서 조합원 안내 사이트

조합 검토안과 DL이앤씨 제시안의 주요 쟁점 조항을 조문 그대로 비교해 보여주는
조합원 안내용 정적 웹사이트입니다. 조합 안내자료(2026. 8. 20. 「조합 검토(안) · DL이앤씨
공사도급계약서 비교」)를 근거로 제작되었습니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 사이트 본체 (단일 파일, CSS/JS 인라인) |
| `og.png` | 카카오톡·SNS 공유 미리보기 이미지 (1200×630) |
| `docs/조합검토안-DL제시안_주요조항_비교안내_2026-08-20.pdf` | 조합 안내문 원본 (사이트에서 내려받기 제공) |

사이트 섹션: 지금 상황 30초 요약(3단 스토리) → 안내말씀 → 숫자로 보는 주요 쟁점(6개 타일)
→ 쟁점 요약표(11행, 행 클릭 시 해당 쟁점 이동, 모바일은 세로 스택형으로 표시) → 쟁점 바로알기(11개 조항 비교, 상단 퀵점프 바)
→ 성남시 질의·회신 → 협상 경과·일정 → FAQ → 공지·자료실 → 조합의 약속.

시각 요소: 증액·연장 사유 비교 막대, 미분양 할인 한도 비교 막대와 1,800억 원 손실 시산 스택 바,
공사비 증액 경로 플로우(연장 사유 → 공기 연장 → 추가경비 반영 → 증액). 모두 조합 안내자료 수치 기준입니다.
스크롤 연동 모션: 히어로 순차 등장, 핵심 수치 카운트업, 비교 막대·손실 구간 성장, 성남시 '불가' 도장 효과.
모션은 기기의 '동작 줄이기' 설정과 무관하게 재생됩니다(해당 설정 시 페이지 이동 스크롤만 즉시 처리).
자바스크립트가 꺼진 환경에서도 최종 수치와 그래프 값은 그대로 표시됩니다.

## GitHub Pages 배포

현재 설정: Public 저장소, **Settings → Pages**에서 `claude/housing-redevelopment-guide-site-sdd9i5`
브랜치(기본 브랜치) / `/ (root)` 배포. 이 브랜치에 커밋을 푸시하면 1~2분 내 자동 반영됩니다.

- 주소: `https://sang2office.com` (커스텀 도메인 · CNAME 파일로 설정)
- 기존 주소 `https://dkdldrmtit.github.io/sangdaewon2/` 는 새 도메인으로 자동 리다이렉트됩니다
- 빌드 상태 확인: 저장소 → **Actions** → "pages build and deployment"

### 배포가 실패할 때

- **"Multiple artifacts named \"github-pages\"" 오류**: GitHub 쪽 일시 장애입니다.
  실패한 실행을 Re-run 하지 말고, 새 커밋을 푸시해 새 실행을 만들면 해결됩니다.
  (같은 실행을 재시도하면 이전 시도의 산출물이 남아 동일 오류가 반복될 수 있습니다.)
- 반영이 안 보일 때: 브라우저 캐시일 수 있으니 주소 뒤에 `?v=숫자`를 붙여 열어 확인하세요.

> 저장소 이름을 바꾸면 주소도 바뀝니다. 주소가 달라질 경우 `index.html` 상단의
> `og:url` / `og:image` / `canonical` 메타 태그 3곳의 주소를 함께 수정해 주세요.
> (카카오톡 공유 미리보기가 이 주소를 사용합니다.)

카카오톡 공유 미리보기가 갱신되지 않을 때는 [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 캐시를 초기화할 수 있습니다.

## 내용 업데이트 방법

- **공지 추가**: `index.html`에서 `notice-list`를 찾아 `<li>` 한 줄을 추가합니다.
- **자료 추가** (예: 법무법인 지평 종합 검토안, 성남시 공문 스캔):
  1. 파일을 `docs/` 폴더에 넣습니다.
  2. `자료실` 섹션의 해당 카드(`doc pending`)에서 `pending` 클래스를 제거하고,
     `<span class="soon">…</span>`을 `<a class="dl-btn" href="docs/파일명" download>내려받기 ↓</a>`로 바꿉니다.
- 모든 사실 주장·조문 인용은 조합 안내자료를 근거로 하며, 새 주장을 추가할 때는
  근거 문서를 자료실에 함께 게시하는 것을 권장합니다.

## 원문 대비 표기 정정 사항

사이트 제작 시 안내문 PDF의 다음 표기를 교차 확인 후 바로잡아 반영했습니다.

1. PDF 6쪽 표 머리글 "DL이앤씨 제시안 제32조(공사기간 연장)" → **제29조** 로 표기
   (PDF 7쪽 해설 "DL안 제29조 제3항" 및 DL 계약서 전문 목차와 교차 확인, 제32조는 '공사의 시정명령').
2. PDF 24~25쪽 조합 검토안 제11조 ④·⑤항이 인용하는 "제35조" → **제36조** 로 표기
   (제36조가 '계약의 해제 및 해지', 날인 제출본 전문과 교차 확인).
3. "2026월 6월" → "2026년 6월", "재2조제1항" → "제2조 제1항" 등 명백한 오탈자 정규화.
4. DL 제시안 제9조에서 '②' 항이 두 번 표기된 것은 **DL 원문 표기 그대로**이며, 사이트에 각주로 명시했습니다.
